# Repository instructions

- For every requested change to this OS project, update its current development version,
  completed work, next target, and remaining release gates when the change affects them.
  Use the [Australis OS — Development project](https://github.com/orgs/Aurora-softwares/projects/3)
  for current progress. A Git tag is historical release evidence, not the source of the
  current development version.
- `map_to_gui.md` and `VERSIONING.md` along with all markdown checklists will be removed
  one they have been copmpleted. All future checklist items are to be placed on the repository
  project with all relevent information filled out.
- When editing a checklist, use 🟢, 🟡, and 🔴 traffic lights instead of checkbox syntax.
