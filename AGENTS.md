# Repository instructions

- For every requested OS change, use the [Australis OS — Development project](https://github.com/orgs/Aurora-softwares/projects/3)
  for current progress. Update the [versioning guide](https://github.com/Aurora-softwares/Australis-Docs/blob/Development/docs/development/versioning.md)
  in Australis-Docs when the current development version, completed work, next target, or
  remaining release gates change. A Git tag records a past release, not current progress.
- The [GUI roadmap](https://github.com/Aurora-softwares/Australis-Docs/blob/Development/docs/development/gui-roadmap.md)
  and other development documentation live in Australis-Docs. Put future checklist work on
  the development project with the applicable fields filled out.
- When editing a checklist, use 🟢, 🟡, and 🔴 traffic lights instead of checkbox syntax.
